# Feedigo – Smart Food Donation & Distribution Platform

A Flutter-based mobile application that connects food donors, food banks, and beneficiaries, with AI-assisted smart matching using Decision Tree Algorithm to reduce food waste and improve distribution efficiency.

---

## Project Overview

Feedigo is designed to streamline the donation and distribution of surplus food. It allows:

- **Donors:** Easily list food donations with details like food type, quantity, location and expiry date.  
- **Food Banks:** Request available donations, track request statuses, approve or decline requests and schedule pickups.  
- **Beneficiaries:** Request available donations, track request statuses, approve or decline requests and schedule pickups. 
- **AI Matching Module:** Smartly matches requests with donations based on food type, quantity, location, and expiry.

This project was developed as part of my **Final Year Project (FYP)**, strengthening skills in Flutter development, Firebase integration, and AI-assisted systems.

---

## Key Features

- Role based dashboards
- User registration and login for donors, food banks, and beneficiaries  
- Create, edit, and cancel food donations (Donors) 
- Browse and request available donations (Food Banks, Beneficiaries)  
- Approve or decline requests and schedule pickups (Food Banks, Beneficiaries)  
- AI-assisted smart matching for donations for optimized distribution (Food Banks, Beneficiaries)  
- In-app status tracking
- External navigation support (Google Maps)
